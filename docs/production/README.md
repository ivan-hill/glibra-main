# Glibra Production Rights Center

This directory defines the production-rights framework used by the provider onboarding site.

## Operating model

Provider onboarding and production authorization are separate.

A host or local provider may indicate interest in appearing in Glibra content or making a location available for filming. That preference does not itself grant filming rights.

For a specific production, Glibra issues the applicable agreement set and tracks executed documents as part of chain-of-title.

## Agreement set

- Production Deal Memo
- Location Agreement
- Talent & Appearance Release
- Principal Performer Agreement
- Dance Performer Agreement
- Choreographer Services Agreement
- Music Rights & Performance Agreement
- Crew Independent Contractor Agreement
- Production Confidentiality Agreement
- Materials Release
- Minor Participant Release
- Production Safety & Conduct Acknowledgment
- Chain-of-Title Checklist

## Release workflow

1. Create production record.
2. Identify parties and rights needed.
3. Issue project-specific agreement.
4. Capture affirmative electronic-signature consent.
5. Preserve the exact agreement version and signed copy.
6. Record audit data.
7. Track exceptions and unresolved rights.
8. Mark production rights-clear only after all required categories are complete.

## Counsel gate

Before any template is treated as final, production or entertainment counsel should review:
- legal entity name;
- indemnity and limitation language;
- insurance requirements;
- worker classification;
- wage and labor obligations;
- music ownership and samples;
- union or guild obligations;
- child-performer requirements;
- privacy policy coverage for signature audit data;
- state-specific execution formalities.
